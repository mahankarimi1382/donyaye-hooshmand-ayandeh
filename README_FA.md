# بسته بازطراحی جامع UI/UX وب‌سایت «دنیای هوشمند آینده»

**نوع بسته:** دستور اجرای ایجنت کدنویسی + شرح پروژه + معماری اطلاعات + Design System + نقشه راه اجرایی + QA + منابع متن‌باز  
**نسخه:** 1.0  
**تاریخ تهیه منابع:** ۲۶ اکتبر ۲۰۲۶

## هدف
این بسته برای بازنویسی کامل تجربه و رابط کاربری فرانت‌اند وب‌سایت شرکت **دنیای هوشمند آینده** آماده شده است. حوزه فعالیتی که کارفرما اعلام کرده، **نهاده‌های دامی** است. هدف، ساخت تجربه‌ای حرفه‌ای، قابل اعتماد، سریع، مدرن و قابل توسعه برای مشتریان تجاری و صنعتی است؛ نه صرفاً تغییر رنگ، فونت یا فاصله‌ها.

## شروع سریع
1. این پوشه را در ریشه مخزن سایت قرار دهید یا فایل ZIP را همان‌جا استخراج کنید.
2. فایل `00_MASTER_PROMPT_FA.md` را به ایجنت بدهید و از او بخواهید تمام اسناد بسته را بخواند.
3. آدرس GitHub / سایت زنده را به ایجنت بدهید، اگر در محیط او وجود ندارد. در این بسته آدرس وب‌سایت یا مخزن ارائه نشده است؛ بنابراین این فایل‌ها یک مشخصات اجرایی عمومی اما مخصوص کسب‌وکار شرکت هستند، نه گزارش ممیزی مخزن واقعی.
4. اجازه ندهید ایجنت فقط یک طرح اولیه یا صفحه Home بسازد؛ خروجی باید تمام صفحات و حالات تعامل را شامل شود.
5. قبل از merge/deploy، چک‌لیست `07_QA_ACCEPTANCE_FA.md` را اجرا کنید.

## اصول غیرقابل مذاکره
- وب‌سایت باید با هویت و حوزه **نهاده‌های دامی** مرتبط باشد، نه یک قالب عمومی شرکتی یا فروشگاه نامرتبط.
- زبان پیش‌فرض پیشنهادی فارسی با RTL صحیح است. اگر سایت فعلی چندزبانه است، زبان‌ها و URLهای موجود باید حفظ شوند.
- اطلاعات ناموجود شرکت، محصول، ظرفیت، آزمایشگاه، گواهی‌نامه، تأمین‌کننده، بازار صادراتی و آمار فروش نباید ساخته شوند.
- ابتدا پشته فنی و منطق فعلی بررسی شود؛ تغییر فریم‌ورک، حذف endpoint یا تعویض وابستگی‌ها صرفاً برای سلیقه بصری مجاز نیست.
- تمام دکمه‌ها و فرم‌ها باید رفتار واقعی داشته باشند؛ CTA تزئینی یا فرم نمایشی پذیرفته نیست.
- وب‌سایت باید از موبایل تا نمایشگرهای بزرگ، با کیبورد و با ابزارهای دسترس‌پذیری قابل استفاده باشد.
- منابع GitHub معرفی‌شده، گزینه‌های بررسی هستند نه دستور نصب همگانی. انتخاب نهایی باید پس از بررسی پشته، مجوز، نگهداری، سازگاری، وزن bundle و نیاز واقعی انجام شود.
